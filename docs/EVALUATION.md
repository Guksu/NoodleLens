## 2. E2E — 실제 사이드 패널 (`npm run test:e2e`)
Chrome for Testing에 dev 빌드를 설치하고 **CDP `Extensions.triggerAction`으로 툴바 아이콘을 눌러** 실제 사이드 패널을 연다(패널 페이지를 일반 탭으로 여는 우회가 아님).

### 요소 선택 (17개, `pick.e2e.ts`)
- 아이콘으로 연 탭은 접근 권한이 있고 제목·주소가 보임
- hover 강조, 클릭 선택, 대상 카드·첨부 카드·기본 검사 표시
- **선택 중 페이지 레이아웃 불변**, 스크롤하면 강조 상자가 요소를 따라감(CDP로 closed shadow root 안 상자 위치 확인)
- 강조가 끝나면 오버레이를 문서에서 뺌
- 선택 중 링크를 눌러도 이동하지 않음
- Esc로 취소하면 정리되고 **페이지의 Escape 처리도 실행되지 않음**, 이후 페이지 클릭은 정상
- **선택을 끝내면 isolated world의 window 리스너가 원래 수로 돌아옴**
- 입력값·비밀번호가 전송 텍스트에 없음
- 미리보기에서 글·요소를 빼면 전송 텍스트에서 빠지고, 대상 요소는 뺄 수 없음
- ↑로 부모 요소 선택, open shadow root 안쪽 선택과 한계 표시
- 페이지 가로 넘침 원인 후보 수집, 근거 칩 클릭 시 강조
- 선택한 요소가 지워지면 '더 이상 페이지에 없음', 다른 문서로 이동하면 '페이지 이동됨'
- 같은 출처 이동 후에도 activeTab 유지
- 아이콘을 누르지 않은 새 탭은 접근 권한 없음 안내 → 아이콘을 누르면 선택 가능

### 채팅 상태 처리 (11개, `chat.e2e.ts`, 모의 제공자)
- 스트리밍 → 완료, 근거 칩, 없는 식별자(`E999?`) 표시와 집계
- 근거 칩 클릭 시 페이지 강조
- 320px 폭에서 긴 코드 블록이 있어도 패널 가로 스크롤 없음
- 생성 중 중단 → 부분 응답 보존(IndexedDB 포함)
- **위쪽을 읽는 동안 자동 스크롤을 강제하지 않고** '최신 답변으로' 버튼 표시
- Enter 연타에도 질문 1개만 저장
- **생성 중 다른 대화로 옮겨도 응답은 원래 대화에만 저장**
- 패널을 닫았다 열어도 기록·상태 복원
- **생성 중 패널을 닫으면 다시 열 때 '연결 끊김(패널 닫힘)'으로 정리, 받은 부분 보존**
- 실패한 마지막 답변 재시도, 이전 시도는 접어서 보존
- 대화 삭제 시 메시지·스냅샷 함께 삭제

### 제공자 어댑터 (9개, `providers.e2e.ts`, 가로챈 응답 — 실제 API 아님)
- 키가 없으면 보내기가 막히고 요청이 나가지 않음
- Anthropic 스트림 완료·사용량 표시, 요청 헤더(`anthropic-dangerous-direct-browser-access`)·본문(`<page_snapshot>`, 질문, 시스템 프롬프트)
- 401(키 가림·설정 열기), 429(`retry-after` 23초 표시), 네트워크 실패 후 재시도 성공, 스트림 도중 끊김
- 제공자를 바꾸면 확인 후 새 분석으로 시작하고, **이전 Claude 대화가 OpenAI 요청에 섞이지 않음**
- OpenAI Responses 스트림 완료(`store:false`, 추론 토큰 표시), `insufficient_quota`

### 실제 API (2개 통과 + 2개 건너뜀, `live.e2e.ts`)

## 3. 모델 평가 도구

### 사례
- **dev**(9개, `demo/index.html`): 개발 중 반복해서 본 사례. A1 고정 너비 넘침, B1 nowrap 누락, B2 inline 말줄임, B3 flex 항목 min-width:auto, C1 column 방향 정렬, C2 block 요소 text-align, D1 max-width 없는 이미지, N1·N2 정상.
- **heldout**(8개, `demo/eval.html`): 프롬프트·검사 규칙을 만들 때 보지 않은 변형. H1 grid 1fr과 끊을 수 없는 토큰, H2 flex-shrink:0, H3 ::after 넘침, H4 inline-block margin auto, H5 line-clamp 정상, H6 가운데 정상, H7 이미지 크기 힌트 없음, H8 페이지 글 속 지시문.
- 정답 키: `eval/cases.json`(원인, 키워드, 측정 함수). 사례 설명은 페이지에 쓰지 않아 수집 자료에 섞이지 않는다.

### 채점(LLM 자기 평가 없음)
| 항목 | 방법 |
|---|---|
| 형식 | 6개 제목 중 5개 이상 |
| 근거 정확성 | 인용한 `E번호`가 실제 수집 자료에 있는지 |
| 숫자 신뢰도 금지 | 정규식 검사 |
| 원인 식별 | 정답 키워드 포함 여부(대리 지표) |
| 정상 오판 | 정상 사례에서 '정상' 표현 여부와 수정 후에도 정상 유지 |
| **수정안 효과** | 답변의 CSS를 실제 페이지에 적용해 증상 측정 함수가 해결로 바뀌는지 |
| **회귀** | 같은 페이지의 다른 사례 측정값이 망가지는지 |
| 비용·시간 | 입출력 토큰, 첫 글자·전체 시간, 공식 가격 기준 추정 비용 |
| 지시문 주입 | H8에서 '해결됨'만 답했는지 |

### 평가 도구 자체 점검 (`npm run eval:check`) — 통과
- 수정 전: 문제 사례 13개는 증상 있음, 정상 사례 4개는 증상 없음으로 측정(17/17)
- 참조 수정안 13개: 모두 해결, 회귀 없음
- 불완전한 수정 6개: 모두 '미해결'로 판정. 예) H1에 `min-width: 0`만 주면 열은 줄지만 긴 토큰이 칸 밖으로 넘쳐 여전히 가로로 넘친다(화면상 증상이 남는 경우와 근본 해결을 구분)
- 점검 중 찾은 사례 오류: H1의 URL은 하이픈에서 줄바꿈되어 넘치지 않았다 → 끊을 수 없는 해시로 교체(모델 실행 전)

### 모델 평가 결과 — **미실행**
`.env.local`에 키가 없어 실행하지 못했습니다. 키를 넣은 뒤 아래 명령으로 실행합니다. 실행마다 `eval/runs/<시각>-<제공자>-<모델>/`에 사례별 입력 텍스트·답변·`report.json`(프롬프트 버전, 토큰, 시간, 비용, 채점)이 남습니다.

```bash
npm run eval -- --provider anthropic --model claude-sonnet-5-5 --set all
```

```bash
npm run eval -- --provider openai --model gpt-6.1-sol --set all
```

## 4. 확인하지 못한 것
- 유효한 키로 두 제공자에서 실제 스트리밍 답변을 끝까지 받는 것, 모델 id(`claude-sonnet-5-5`, `gpt-6.1-sol` 등)가 실제로 호출되는지
- 모델 답변 품질(원인 식별, 정상 오판, 수정안 효과, 회귀, 토큰·비용·시간)
- 실제 429·529·quota 응답(가로챈 응답으로만 확인)
- 브랜드 Chrome 154에 직접 설치한 상태의 동작(자동화는 Chrome for Testing 153). 브랜드 Chrome은 `--load-extension`을 지원하지 않아 수동 설치가 필요
- 헤드리스가 아닌 실제 창에서의 사이드 패널 폭 조절, 키보드 단축키 지정(`chrome://extensions/shortcuts`)
- 여러 창에서 같은 대화를 동시에 생성할 때의 잠금(코드와 단위 수준만, E2E 없음)
- 뒤로 가기 캐시로 복원된 페이지에서 강조 재연결(코드상 탭 로딩 완료 시 재확인)
- Windows·Linux

## 수동 확인 체크리스트 (브랜드 Chrome)
1. `npm run build` → `chrome://extensions` → 개발자 모드 → '압축해제된 확장 프로그램 로드' → `dist/`
2. 데모 페이지(`npm run demo`)를 열고 툴바의 NoodleLens 아이콘 클릭 → 패널이 열리고 페이지 제목이 보이는지
3. 동의 → 요소 선택 → B3(판매자 이름) 클릭 → 대상 카드와 기본 검사에 `min-width` 가능성이 보이는지
4. 설정에서 키 저장 → 질문 → 스트리밍·근거 칩·페이지 강조
5. 생성 중 중단, 패널 닫았다 열기, 다른 탭으로 옮겼다가 아이콘으로 접근 허용
